# Democracy Without Candidates

Projeto de democracia direta para cidadãos proporem, debaterem e votarem decisões coletivas, com regras definidas por plebiscito em cada país.

**Em planejamento. Ainda não há aplicação disponível para uso.**

## Funcionalidades previstas

- Propostas de leis, coleta de assinaturas e debate.
- Votação com privacidade por padrão.
- Configuração de regras por plebiscito e auditoria de resultados.
